This is a draft template for future blog posts. Drafts in `_drafts/` are not built or
published unless Jekyll is run with `--drafts`. To publish a real post:

1. Move this file (or a copy) into `_posts/`.
2. Rename it to `YYYY-MM-DD-your-post-title.md`.
3. Set a real `title` in the front matter above (`date:` is optional if it's in the filename).
4. Write the post body here in Markdown.

It will then automatically show up on the [Blog]({{ site.baseurl }}/blog/) page.
